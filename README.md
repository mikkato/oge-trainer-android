# OgeTrainerAndroid

**Автономное** Android-приложение «Тренировочная система» (ОГЭ-тренажёр). Сервера нет: контент поставляется банком внутри APK, прогресс хранится на устройстве, генерация и проверка развёрнутых ответов работают только через LLM-провайдера, которого пользователь настраивает сам (любой OpenAI-совместимый endpoint).

Состояние: **проектирование завершено, контент выгружен**. Кода приложения нет.

## Банк контента

`assets/content-v1/` — 1,7 МБ: `subjects.json`, `topics.json` (103 темы), `theories.json` (103 конспекта), `tasks.json` (407 задач: 317 коротких, 81 развёрнутая, 4 изложения, 5 сочинений), `illustrations/` (69 SVG), `backgrounds/` (6 SVG), архивы попыток и освоения. Счётчики и sha256 — в `meta.json`. Скрипты выгрузки и предгенерации — `tools/server-export/`.

## Коротко

- Устройство: Android 12+ (`minSdk 31`), `targetSdk 36`.
- MVP (ученик + родитель + провайдер): 112 ч + 15 % = 129 ч ≈ 4 недели при 32 ч/нед.
- Полная версия (админка, перенос данных, GitHub-релиз): 162 ч + 15 % = 186 ч ≈ 5,8 недели.
- Первый гейт — рендеринг формул (WebView + офлайн-KaTeX против Markwon + jlatexmath), решается в первые три дня.
- Распространение — GitHub Releases по тегу `vX.Y.Z`, установка APK по ссылке.
