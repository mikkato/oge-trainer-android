# Вопросы для решения (контент по ФРП + трек ОГЭ)

Готово без тебя: генерация 1701 темы (3 волны), импортёр в БД, фильтр «ФРП» в банке.
Ниже — решения, которые я намеренно НЕ принял сам, потому что они меняют продукт.

## 1. Приёмка 8,3 тыс. черновиков
Задачи предгенерированы моделью и лежат как `trusted=0` — ученик их не увидит,
пока админ не примет. Варианты:
  a) ручная приёмка тема за темой (сейчас так, но 8 тыс. — нереально);
  b) **массовая приёмка с выборочной проверкой**: принимаем всё, кроме флагом
     помеченных (дубли, слишком короткий ответ, «верно/неверно» подряд) — советую это;
  c) автоприёмка по порогу second-pass: вторая модель проверяет эталонный ответ,
     расхождение → в ручную очередь.
Вопрос: b или c? (c дороже по времени генерации, но чище.)

## 2. Предметы «второго эшелона»
План включает музыку (72 темы), ФИЗО (48), труд (87), ДНКР (77), ИЗО, ОРКСЭ.
Задачи по ним генерируются слабо-осмысленно («в волейболе мяч ногами трогать можно?»).
  a) оставить всё (полнота ФРП);
  b) в тренаже показывать только «ядра»-предметы (рус, мат, физ, хир, биол, гео, ист,
     общ, инф, лит, ин.яз), остальные — только дерево тем без задач.
Совет: b, список ядер — подтверди состав.

## 3. ОГЭ как экзамен — глубина
Сейчас: 405 доверенных задач ОГЭ + диагностика. Что строить дальше:
  a) «Пробник ОГЭ»: таймер на предмет, N заданий из банка, итог в баллах ≈ шкале ФИПИ;
  b) + отдельный экран-трек «Экзамены» в навигации (отдельный mastery, вне классов);
  c) + привязка тем ФРП 9 класса к номерам заданий ОГЭ (матрица «пропустил → вот тема»).
Вопрос: какой объём? Матрица (c) — самая полезная и самая трудоёмкая.
