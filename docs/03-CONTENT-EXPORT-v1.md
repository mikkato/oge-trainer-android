# Выгрузка контента с сервера — v1

Дата: 13.11.2026, до демонтажа сервера. Источник: `170.168.100.53:/home/mikkato/oge-trainer/data/app.db` (SQLite, `oge-trainer` 0.4.0).

## 1. Причина и порядок

Сервер выводится из эксплуатации, а приложение становится автономным (см. `01-TZ-android-v2.md`). В системе контент не хранился как банк — он генерировался по запросу. К моменту выгрузки в базе было **31 задача и 47 конспектов на 103 темы**, то есть при демонтаже «как есть» приложение осталось бы почти без материала.

Поэтому выполнено две операции:

1. **Выгрузка** существующего: кодификатор, конспекты, задачи, иллюстрации, фоны, программы, история попыток, освоение.
2. **Предгенерация** недостающего через тот же DeepSeek-ключ сервера: конспекты для тем без теории, банк задач по каждой теме и типу. Записи добавлялись в базу сервера, после чего выгрузка выполнена повторно.

Скрипты сохранены в `tools/server-export/` (запускаются внутри контейнера `oge-api` с `PYTHONPATH=/app`).

## 4. Структура JSON (контракт банка)

```
subjects.json   [{id, code, title, description}]
topics.json     [{code, title, subject, parent, order, source}]
theories.json   [{topic, title, content(markdown+LaTeX)}]
tasks.json      [{subject, topic, type, prompt, answer, solution, trusted, max_points}]
programs.json   [{username, type, grade, subjects[]}]
users.json      [{id, username, full_name, role}]            # без паролей
attempts-archive.json [{username, topic, type, prompt, answer_text, correct, score,
                        points, max_points, feedback, created_at}]
mastery-archive.json  [{username, topic, mastery, attempts_count, last_attempt_at}]
illustrations/<topic_code>.svg, backgrounds/<code>.svg
```

Типы: `short`, `extended`, `izlozhenie`, `sochinenie`. `max_points`: 1–2 для short, 2 для extended (физика-чекер мог вернуть 2–3), 6 для изложения, 7 для сочинения.

## 5. Что проверено и что нет

Проверено скриптом на локальной копии: целостность (sha256), покрытие тем конспектами (103/103), распределение задач по предметам и типам, отсутствие пустых условий и пустых ответов у коротких задач, объём ассетов.

Выборочная проверка качества (6 случайных задач глазами): 5 решений арифметически верны (путь при равноускоренном движении 45 м; медиана 159; `a_n = n²+1`, `a_32 = 1025`; сумма корней 7; граница с Казахстаном), 1 вызывает сомнение — задание на соответствие по физике с ответом «А — 1, Б — 2, В — 2» (повтор одной и той же цифры в двух позициях возможен, но требует проверки учителем).

Не проверялось: весь массив 407 задач (выборочно 6), корректность 63 сгенерированных конспектов, соответствие сгенерированных заданий официальному кодификатору ФИПИ. Это работа родителя в очереди проверки (FR-705) либо внешней проверки через провайдера.

## 6. Пробелы банка (известные)

1. У двух тем нет коротких задач: `bio.animals.1` («Строение и жизнедеятельность животных») и `phys.quantum` («Квантовые явления») — модель выдавала дубли уже существующих условий, дубли отброшены дедупликацией по `content_hash`.
2. У 7 тем всего 1 короткая задача — покрытие тонкое, при активной практике тема вырабатывается за один подход.
3. Изложений 4, сочинений 5 — для офлайн-практики письменных частей мало; без провайдера ученик быстро исчерпает материал.
4. Задачи с наборами цифр и соответствиями требуют аккуратной нормализации ответа: `А — 1, Б — 2` и `А-1,Б-2` должны считаться одним ответом, иначе локальная проверка (FR-404) забракует верный ответ. Решение заложено в ТЗ требованием унификации тире и разделителей.

## 7. Что осталось на сервере (не выгружено сознательно)

- Хеши паролей (`bcrypt`) — приложение заводит профили заново (OQ-5).
- `ai_config.api_key` — пуст, используется ключ из env контейнера. **Сам ключ DeepSeek из `.env` нужно забрать до демонтажа**, если планируется тот же тариф.
- Логи nginx и SQLite-мусор (`debug_tmp.py`, `.env.bak`) — не нужны.

## 8. Воспроизводимость

```bash
# внутри контейнера oge-api
sudo docker cp tools/server-export/export_v2.py oge-api:/tmp/
sudo docker exec -w /app oge-api sh -c "python /tmp/export_v2.py"   # экспорт в /home/mikkato/content-export
```

Порядок предгенерации, если банк нужно расширить: `pregenerate_theories_and_short.py` → `pregenerate_extended_and_writing.py` → `pregenerate_sochineniya_themed.py` → `export_v2.py`. Все скрипты идемпотентны: повторный прогон не дублирует записи.
