# ТЗ: Android-приложение «Тренировочная система» — v2 (автономное)

Версия 2 меняет архитектуру: **сервер выводится из эксплуатации**, приложение становится самодостаточным. Реверс-основа — `00-REVERSE-oge-trainer-web-v1.md`; состав выгруженного контента — `03-CONTENT-EXPORT-v1.md`.

Изменения v2 относительно v1:
1. Убран серверный контур: клиент не зависит от `train.mytolm.ru`, весь контент и прогресс — на устройстве.
2. Аутентификация локальная (профили), а не JWT.
3. В LLM-слое любой OpenAI-совместимый endpoint, настраиваемый в приложении (требование заказчика).
4. `minSdk` поднят до 31 (устройство заказчика — Android 12+).
5. Освоение, отчёты, кросс-рекомендации считаются локально (порт правил из веба).
6. Распространение — GitHub-репозиторий и APK по ссылке из Releases; подпись — keystore из GitHub Secrets.
7. Добавлены экспорт/импорт прогресса (устройств может быть больше одного, синхронизации нет).
8. Удалены серверные требования FR-S1…S8 (сервер демонтируется после реверса).

## 1. Термины

| Термин | Значение |
|---|---|
| Банк | Предзагруженный набор конспектов и задач, поставляемый внутри APK |
| Профиль | Локальная учётная запись с паролем и ролью (`student`/`parent`/`admin`) |
| Провайдер | Внешний OpenAI-совместимый endpoint для генерации и проверки заданий |
| Освоение | Локальная величина 0..1 по теме, EMA по результатам попыток |
| Доверенная задача | Задача, помеченная родителем как проверенная |

## 2. Цели

| ID | Цель |
|---|---|
| G-1 | Полный цикл обучения работает **без сети и без сервера**: предмет → тема → теория → задача из банка → проверка короткого ответа → прогресс |
| G-2 | При подключённом провайдере любого вендора доступны генерация новых задач и проверка развёрнутых ответов, изложений и сочинений |
| G-3 | Родитель видит отчёт по детям, очередь проверки задач и управляет профилями — на том же устройстве |
| G-4 | Установка по ссылке из GitHub Releases, обновление — заменой APK; данные при обновлении не теряются |
| G-5 | Ни одна функция веб-системы не потеряна, кроме серверной части, которой больше не будет |

## 3. Не входит в объём

- Серверная часть, аккаунты в облаке, синхронизация между устройствами (вместо неё — экспорт/импорт файла прогресса).
- Публикация в Google Play / RuStore (распространение — APK).
- Регистрация/восстановление пароля через интернет: пароль меняет администратор устройства.
- Генерация контента без провайдера: без endpoint доступны только банк и проверка коротких ответов точным совпадением.
- Мультиязычность, iOS, планшетная раскладка сверх адаптивной.
- Проверка орфографии и грамматики сочинений без модели.

## 4. Роли (локальные)

| Роль | Возможности |
|---|---|
| `student` | свои предметы и темы, теория, задачи, разбор, свой прогресс и история |
| `parent` | отчёты по ученикам (агрегаты, слабые темы, рекомендации), очередь проверки задач, пометка доверенных, смена своего пароля |
| `admin` | профили (создание, программа, пароль, сброс, удаление), настройка провайдера, экспорт/импорт прогресса, очистка кэша |

Первый запуск: мастер создания администратора (логин, имя, пароль ≥ 6). Пароли — PBKDF2-HMAC-SHA256, 210 000 итераций, случайная соль 16 байт; в БД только соль и хеш.

## 5. Архитектура

```
┌──────────────────────── Android 12+ (Kotlin + Compose) ───────────────────────┐
│ ui/  Локальный вход · Предметы · Темы · Теория(Markdown+KaTeX) · Задача       │
│      Разбор · История · Отчёт · Очередь проверки · Админка · Настройки        │
│ domain/  use cases: PickTask, CheckShortAnswer, GenerateTask, CheckWithLlm,    │
│          RecomputeMastery, BuildReport, ImportBank                            │
│ data/    Room (единственный источник истины)                                   │
│          ├ assets/bank/*.json — поставляемый банк (импорт при первом запуске)   │
│          ├ LlmClient — OpenAI-совместимый /chat/completions (Ktor)             │
│          └ ProviderStore — base_url/model/ключ (ключ в EncryptedSharedPrefs)   │
└───────────────────────────────────────────────────────────────────────────────┘
                          │ только при настроенном провайдере
                          ▼
              любой совместимый endpoint (DeepSeek, OpenAI, OpenRouter,
              llama.cpp/Ollama в локальной сети, корпоративный шлюз)
```

Решения:

| Решение | Обоснование |
|---|---|
| Клиент не зависит от сервера | Сервер демонтируется по решению заказчика; зависимость сделала бы приложение нерабочим |
| Room — единственный источник истины | Нет сервера — нет второго источника; отчёт и освоение считаются из локальных попыток теми же формулами, что в вебе |
| Банк в `assets` + импорт в Room | Работает сразу после установки, без сети; импорт идемпотентен по ключу `(topic, type, hash(prompt))` |
| Провайдер настраивается в приложении, а не зашит | Требование заказчика: любой custom endpoint; заодно снимает привязку к DeepSeek после смерти сервера |
| Проверка коротких ответов локальная | Нормализация как в вебе (регистр, пробелы, запятая→точка): работает офлайн, бесплатно, мгновенно |
| Развёрнутые/изложение/сочинение — только через провайдера | Критерии ИК1–ИК3 и СК1–СК4 невозможно воспроизвести детерминированно |
| Экспорт/импорт JSON вместо синхронизации | Два ребёнка на двух телефонах — реальный сценарий; файл прогресса дешевле сервера |

## 9. Безопасность

- Пароли — PBKDF2, постоянное время сравнения, блокировка после 5 попыток.
- Ключ провайдера шифруется Keystore-ключом; при смене ключа/сбросе данных — только повторный ввод ключа, банк и прогресс не страдают.
- `allowBackup=false`, `dataExtractionRules` — исключить базу и prefs из облачного бэкапа.
- `network_security_config`: cleartext только для приватных подсетей (FR-509), пиннинг не используется (Let's Encrypt и локальные endpoint).
- Данные ребёнка не покидают устройство, кроме запросов к явно настроенному провайдеру; в запросе уходит текст задания и ответ — это предупреждение показывается при первом включении провайдера.
- Экспорт прогресса — файл с явным предупреждением, что в нём есть ответы ребёнка.

## 10. Дизайн

Токены переносятся из веба без изменений: фон `#0F1115`, поверхность `#1C2230`, поле `#262D3B`, границы `#384052`, текст `#F2F4F7`, вторичный `#AEB8C6`, акцент `#FF6B5C`, успех `#6EE7A0`, ошибка `#F87171`, частичный балл `#F5C76B`; радиусы 8 и 12–14; тени `0 4px 18px rgba(0,0,0,0.35)`; фоны-обои из банка (6 SVG).

Требования заказчика: плотная компоновка (между строками списков 6–8 dp, между блоками 12 dp), без декоративных заливок и служебных подписей на рабочих экранах (номер сборки — только в админке), элементы одной строки — по общей оси, размеры — в процентах от базовых значений темы.

| AC-10 | Дистрибуция: релиз `v1.0.0` в GitHub Releases, установка APK по ссылке на чистом устройстве, версия и отпечаток сертификата совпадают с README |
