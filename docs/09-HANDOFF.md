## 1. Что это

Автономный Android-клиент ОГЭ-тренажёра. Сервера нет: банк контента внутри APK, прогресс в локальной SQLite, генерация и проверка текстов — встроенным llama.cpp (GGUF на устройстве) либо внешним OpenAI-совместимым endpoint.

- Репозиторий: `github.com/mikkato/oge-trainer-android`, ветка `main`
- Версия: `versionCode 9`, `versionName 0.6.0`
- APK: debug ~61 МБ (bloat pre-existing, причина не исследована)
- Тесты: 49 JVM-тестов, все зелёные

## 3. Что НЕ проверено

- **Реальный ARM-телефон.** Всё проверялось на эмуляторе x86_64 (AVD `LSDF_Pixel_36`, API 36). Нативные `libllama.so`/`libggml*.so` под `arm64-v8a` собраны, но на устройстве не запускались.
- **Модели 3B и 7B.** На эмуляторе блокируются бюджетом памяти («нужно 6 ГБ ОЗУ, на устройстве 3,8 ГБ»). Проверены только Gemma 1B и Qwen 1,5B.
- **Мягкая остановка генерации при нехватке памяти** (порог 220 МБ) — не воспроизведена.
- **Удаление профиля из таблицы админки** — кнопка есть, сквозной UI-тест не зафиксирован.
- **Качество проверки крупной моделью.** 1B-модель размечает критерии «met», но комментарии не по заданию; 1,5B даёт связный разбор. Вывод: вердикт модели — подсказка проверяющему, не оценка.

## 4. Пробелы в контенте (главное на следующий заход)

1. **Задания для 5–8 классов есть только по математике**: шаблоны (`LocalTemplates`) дают дроби, натуральные числа, НОД/НОК, уравнения, площади, проценты; плюс 3 задания, сгенерированные моделью. Русский язык, география, биология закрыты конспектами, но без задач.
2. **Шаблоны покрывают математику, физику, химию.** Русский (орфография, пунктуация по классам) не поддержан — генерация уходит на модель, а модель без приёмки в практику не попадает.
3. **Классы 1–4 и 10–11** не поддержаны: темы заведены для 5–9, у 1–4 нет ни тем, ни контента.
4. **Темы ОГЭ привязаны к 9 классу целиком.** Ученик 8 класса их не увидит, хотя часть материала ему доступна — при необходимости вводить `grade` для отдельных ОГЭ-тем.

## 6. Как поднять окружение на новой машине

```bash
# Windows, git-bash
export JAVA_HOME=D:/LSDF/runtimes/jdk21          # JDK 21
export ANDROID_HOME=D:/LSDF/android/sdk          # SDK, platform-tools, NDK 28.2.13676358, CMake 3.22.1
cd D:/MyProjects/OgeTrainerAndroid
./gradlew :app:testDebugUnitTest                 # 37 тестов
./gradlew :app:assembleRelease                   # APK: app/build/outputs/apk/release/
```

Секретов в репозитории нет: `keystore.properties`, `.secrets/`, `*.jks`, `local.properties` в `.gitignore`. Для подписанного релиза нужны keystore и пароль — запросить у владельца отдельным каналом.

Эмулятор: AVD `LSDF_Pixel_36`, обёртка `emu.cmd`, скилл `android-emulator`. `adb` = `$ANDROID_HOME/platform-tools/adb.exe`.

```
app/src/main/cpp/                llama.cpp (вендор, 186 МБ, без .git) + llm_jni.cpp
```

Ключевые решения, которые не стоит менять без причины:

- **SQLite напрямую, без Room** — KSP несовместим с Kotlin 2.4.x при AGP 9.5.1.
- **WebView + офлайн KaTeX/marked** для markdown и формул; нормализация формул — в Kotlin (`MarkdownNormalizer`), а не в JS шаблона.
- **Типы заданий в банке**: `short`, `extended`, `izlozhenie`, `sochinenie` (не `detailed`).
- **Сложность** хранится в `origin`: `local:1..3`, `llm-local`, `bank`.
- **Вердикт модели** пишется в `attempts.verdict_json` вместе с именем модели; балл подтверждается человеком.
