# Пайплайн ФРП → тематическое планирование

Источник: реестр ФРП/ФГОС `https://fgosreestr.edsoo.ru/` (SPA, данные через его же API).

## Воспроизведение с нуля

```bash
python3 -m venv venv && venv/bin/pip install pdfplumber

# 1. Список программ и справочник предметов:
#    GET /api/work-program/list?page=0&limit=100&sort=approveTs,desc&isArchived=false
#    GET /api/subject/list?sort=+name
#    → manifest.json (id, subject, level, g1, g2, name на программу; вручную
#      проставлены классы из названий, отфильтрованы тестовые записи probe-*/r2pdf-*)
# 2. Скачивание PDF (важно: рабочий путь work-program, не work_programs):
#    curl -L https://fgosreestr.edsoo.ru/api/files/work-program/{id} -o pdf/{id}.pdf

venv/bin/python extract_tp.py            # pdf/NNN.pdf → fgos_thematic.json
venv/bin/python verify_hours.py          # сверка часов с федеральным нормативом
venv/bin/python build_plan.py \
    ../../app/src/main/assets/school/curriculum.json \
    ../../app/src/main/assets/school/thematic_plan.json
```

## Логика extract_tp.py (пережитые форматы ФРП)

- Раздел начинается с заголовка «ТЕМАТИЧЕСКОЕ ПЛАНИРОВАНИЕ» ЗАГЛАВНЫМИ (прозаические
  упоминания в пояснительной записке игнорируются), не строки оглавления (за заголовком
  идут длинные точки).
- Класс переключается строкой `^N КЛАСС` в тексте или таблице; без заголовков — класс из
  манифеста (ОРКСЭ, второй ИЯ).
- Колонки ищутся по шапке таблицы («Наименование/Название…» + «час/п/п»), живёт на весь
  документ; шапка отличается: с колонкой № и без неё (математика), «Характеристика
  деятельности» и т.п. Ложные срабатывания шапки гасятся лимитом длины строки (<240 симв.).
- Вариант 2 планирования (дублирующий/компактный) отсекается: заголовком
  «ПЛАНИРОВАНИЕ 2» или повторным проходом по классам, у которых уже есть темы.
- Раздел «Проверяемые предметные результаты»/«Система оценивания» и далее — стоп.
- Строки «Общее количество часов/Итого/Всего» — не темы.
- Финальный дедуп по нормализованному (класс, заголовок).

## Известные шероховатости (см. verify_hours.py)

- ИЯ/второй ИЯ: нелинейная структура ФРП, часы на 5–9 суммарные.
- Биология 5–7 (id 156/215), информатика (147/148), математика 7–9 базовый (145):
  частичное извлечение (~40–60% часов) — другие шаблоны таблиц.
- В реестре нет ФРП: обществознание 6–9, ОБЗР 1–11, ИЗО 8–9, индивидуальный проект 10–11.
