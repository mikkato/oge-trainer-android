## Границы модулей

Единственный модуль `:app`, пакеты по назначению; зависимости только в одну сторону:

```
ui/        → domain/ → data/
ui/        не знает про Ktor и Room напрямую
data/      единственное место, где живут DTO, Room и сеть
domain/    чистый Kotlin: use cases и модели, без Android SDK, покрывается JVM-тестами
```

Запрещено: `ui/*` → `data/*` напрямую; сетевые вызовы из Composable; расчёт прогресса и освоения в клиенте (только отображение значений сервера); хранение токена вне `TokenStore`.

## Обязательные правила

1. **Секреты.** Токен — только `TokenStore` (EncryptedSharedPreferences). Ответ ученика, текст задания и токен не попадают в `Log`, в crash-report и в аналитику. `android:allowBackup="false"`.
2. **Контракт сервера — источник истины.** Поля, которых нет в `01-TZ` раздел 4, не выдумывать: сначала проба `curl`, потом код. Клиент толерантен к неизвестным полям JSON.
3. **Ошибки.** 401 → экран входа с сообщением; 403 → «нет доступа»; 502/таймаут → повтор с сохранением введённого текста. Ни одно исключение сети не доходит до UI как краш.
4. **Формулы и markdown** — только через `MarkdownView` (решение по гейту G1, см. `docs/03-G1-renderer.md` после спайка). Второй способ рендера не добавлять.
5. **Плотность интерфейса.** Значения отступов и размеров — из `ui/theme/Spacing.kt` в процентах/кратностях базовой единицы; декоративные цветные заливки, служебные подписи (номер сборки, версия) на рабочих экранах не добавлять; элементы одной строки — по общей оси.
6. **Definition of Done:** сборка зелёная, JVM-тесты зелёные, сценарий проверен на AVD, добавлены/обновлены строки в `docs/03-AC-results.md`, в коммите указан ID требования.

## Ловушки платформы (проверены на других проектах, повторяются)

- `androidx.security:security-crypto` требует инициализации Keystore на устройстве без «часов назад»: после смены системного времени ключ может стать недоступен — предусмотреть повторный вход, а не падение.
- WebView в `LazyColumn` нельзя оставлять с `wrap_content`: высоту задавать измерением через JS-мост, иначе прокрутка «дёргается» и элемент съедается.
- Офлайн-очередь без ключа идемпотентности даёт дубли попыток и двойное изменение освоения — ключ обязателен (FR-S4).
- Таймаут Ktor по умолчанию 10 с меньше серверной генерации конспекта (10–15 с): ставить `requestTimeout` 120 с для `/api/theory` и `/api/attempts`.
- `minSdk 26` требует desugaring для `java.time` в части API-совместимости — включать `coreLibraryDesugaring`, а не понижать версию.

## Формат коммита

`FR-XXX: краткое изменение` — например `FR-501: экран выбора режима ответа`.
